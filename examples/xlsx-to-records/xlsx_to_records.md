# Parse an Excel file to records

The Ballerina `xlsx` library provides functions to parse sheets in Microsoft Excel (XLSX) files into arrays of Ballerina records. Columns are matched to record fields by the header row, and cell values are bound to the field types.

For more information on the underlying module, see the [xlsx module](https://lib.ballerina.io/ballerina/xlsx/latest/).
