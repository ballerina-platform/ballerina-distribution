# Write records to an Excel file

The Ballerina `xlsx` library provides functions to write structured data to Microsoft Excel files in the XLSX format. An array of records can be written to a named sheet in one call, with the record field names becoming the column headers.

For more information on the underlying module, see the [`xlsx` module](https://lib.ballerina.io/ballerina/xlsx/latest/).
