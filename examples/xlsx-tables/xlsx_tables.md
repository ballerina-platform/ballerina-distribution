# Work with Excel tables

The Ballerina `xlsx` library supports Excel tables, which are named, structured ranges within a sheet. A table can be created directly from an array of records and read back by table name.

For more information on the underlying module, see the [xlsx module](https://lib.ballerina.io/ballerina/xlsx/latest/).
